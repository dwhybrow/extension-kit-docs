When you go to **My apps** tab, App Studio's **Dashboard** opens and allows you to:

1.  Create new apps from scratch.
2.  Import apps.
3.  Search for draft and published apps.
4.  Manage your apps using the **Three dots** menu.

![App Studio Overview](https://docs-external.u4pp.com/extensions-kit/app-studio/images/dashboard-new.png)

> Note: The labels will read ERPx or ERP CR depending on which product you are using.

## Manage apps

From the apps displayed in the **Dashboard**, you have the following options for an unpublished app, a published **Standalone** app and a **Business screen** app published to ERPx/CR.

![Available dashboard options for draft app](https://docs-external.u4pp.com/extensions-kit/app-studio/images/dashboard-app-options-draft.png) ![Available dashboard options for published app](https://docs-external.u4pp.com/extensions-kit/app-studio/images/dashboard-app-options-published2.png) ![Available dashboard options for published app](https://docs-external.u4pp.com/extensions-kit/app-studio/images/dashboard-app-options-published.png)

The available options in the **Three dots** menu are:

-   **Go to canvas**: Open the app in the **Canvas** for editing.
-   **View info**: Open a modal showing:
    
    -   _App name_: The name of the app given by the user.
    -   _App ID_: The unique identifier of the app automatically generated by the system.
    -   _Description_: The description of the app given by the user.
    -   _ERPx/CR window title_: The title of the app window in ERPx/CR. Only available when the app is published as a **Business screen** app.
    -   _ERPx/CR menu ID_: The menu ID of the app in ERPx/CR. Only available when the app is published as a **Business screen** app.
    -   _Type_: Regular or system.
    -   _Version number_: The version number. Only for previously published apps.
    -   _Status_: Published, unpublished or never published.
    -   _Last updated at_: The date when the app was last updated.
    -   _Last updated by_: The user who last updated the app.
    -   The URL of the published app.
-   **Edit app info**: Change the app name and description.
    
-   **View all versions**: View all published versions of the app. See [Viewing published versions](https://docs-external.u4pp.com/extensions-kit/app-studio/get-started/how-to-publish-app/#viewing-published-versions) for more details.
-   **Duplicate**: Create a draft copy of the app. If several versions exist, you can select which version you want to copy.
-   **Publish**: Create a URL for publishing your draft app where you are prompted to provide a unique name. When you publish the app its version number is incremented by one. See [Publishing and versioning](https://docs-external.u4pp.com/extensions-kit/app-studio/get-started/how-to-publish-app/) for more details.
-   **Unpublish**: Unpublish the published app and remove its menu item from the ERPx/CR menu.
-   **Create ERPx/CR entry**: For an app that has already been published, create an ERPx/CR menu entry. See [Create an ERPx/CR menu entry](https://docs-external.u4pp.com/extensions-kit/app-studio/get-started/how-to-publish-app/) for more details.
-   **Delete ERPx/CR entry**: For an app that has been published to ERPx/CR, delete the menu entry.
-   **Export**: Export the app definition as a JSON file. Here you select which version you want to export.

## Search apps

You can search for apps on the **Dashboard** by name and/or setting the following filter options:

-   **All**: shows all apps.
-   **Draft**: shows all apps that are not currently published.
-   **Published**: shows all currently published apps.
-   **Published - Standalone**: shows all **Standalone** currently published apps.
-   **Published - ERPx/CR**: shows all **Business screen** apps that are currently published to ERPx/CR.
-   **System**: shows all **System** apps.

> Note: You cannot search for an app using the _App description_ content.
